# Kaikki.fi

Kaikki.fi is a multilingual marketplace MVP for Finland.

## MVP
- Browse and search listings
- Filter by category and city
- Listing details
- Create listing form with photos, title, price, description, location
- Housing for sale and rent
- Finnish, English, Persian (RTL), and Russian UI
- Mobile-first responsive design

## Run
Open `index.html` in a browser.

## Next steps
Authentication, database, image storage, messaging, moderation, reservation payments, maps, and deployment.
